# Sistema Audiovisual

## Descripción
Este proyecto consiste en un sistema de gestión de contenidos audiovisuales desarrollado en Java, aplicando los principios de la Programación Orientada a Objetos (POO).

## Objetivo
Implementar clases que representen diferentes contenidos audiovisuales y sus relaciones con actores, temporadas e investigadores.

## Clases principales
- `ContenidoAudiovisual`: clase abstracta base.
- `Pelicula`: representa una película y sus actores.
- `Actor`: almacena información de los actores.
- `SerieDeTV`: representa una serie y sus temporadas.
- `Temporada`: almacena información de cada temporada.
- `Documental`: representa un documental y sus investigadores.
- `Investigador`: almacena información de los investigadores.
- `VideoYouTube`: representa un video de YouTube.
- `Cortometraje`: representa un cortometraje.
- `PruebaSistema`: permite ejecutar y probar el sistema.

## Tecnologías utilizadas
- Java
- Eclipse IDE
- GitHub
- diagrams.net (Draw.io) para el diagrama UML

## Diagrama UML
El diagrama de clases UML se encuentra en el archivo PDF incluido en este repositorio.

## Pruebas
El sistema se ejecuta mediante la clase `PruebaSistema`, que crea objetos y muestra su información en la consola.
